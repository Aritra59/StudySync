# StudySync

Educational publishers marketing website — practice project focused on CSS flex, grid, and light animation.

**Live demo:** [aritra59.github.io/StudySync](https://aritra59.github.io/StudySync/)

## Features

- Responsive header and hamburger navigation UI
- Hero with CTAs
- Trusted-by logo strip
- Feature cards
- Testimonials
- Newsletter form UI
- Footer with social links

## Tech Stack

- HTML
- CSS
- Google Fonts (Inter)

## Getting Started

```bash
git clone https://github.com/Aritra59/StudySync.git
cd StudySync
```

Open `index.html` in a browser.
